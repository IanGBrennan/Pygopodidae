# Supplement

This directory holds supplementary analyses, figures, the supplementary manuscript, and software-version information.

## Files

- `Pygopodidae_AllLoci_Clean_ASTRAL4.pdf` - ASTRAL4 tree figure or report.
- `Pygopodidae_AllLoci_Clean_wASTRAL.pdf` - wASTRAL tree figure or report.
- `Pygopodidae_LocusSampling.pdf` - Locus-sampling figure.
- `Pygopodidae_MCMCTree_ALL.pdf` - MCMCTree analysis figure or report.
- `Pygopodidae_Supplement_June2026.Rmd` - Supplementary manuscript and analysis source.
- `Pygopodidae_Supplement_June2026.log` - Supplementary document build log.
- `Pygopodidae_Supplement_June2026.pdf` - Rendered supplementary document.
- `Squamata_TLSVL_Total2.pdf` - Squamata total TLSVL figure or report.
- `Squamata_TLSVL_Total2.png` - PNG version of the Squamata TLSVL figure.
- `gCFs.pdf` - Gene concordance-factor figure or report.
- `software_versions.yml` - Software-version record for reproducibility.
