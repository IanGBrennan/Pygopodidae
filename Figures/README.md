# Figures

This directory holds figures and figure assets from the project's analyses, organized by topic.

## Directories

- `BayesTraits/` - BayesTraits figures.
- `Diet/` - Diet-analysis figures.
- `EI/` - Evolutionary-inference figures.
- `Illustrations/` - Illustrations and illustration notes.
- `Tail/` - Tail-analysis figures.
- `Trees/` - Phylogenetic-tree figures.
