# Trees

This directory holds phylogenetic trees and related tree files used for species-level, genus-level, dating, and title analyses.

## Files

- `Pygopodidae_AllLoci_Clean.trees` - Clean all-loci tree set.
- `Pygopodidae_AllLoci_Clean.zip` - Compressed clean all-loci tree files.
- `Pygopodidae_AllLoci_Clean_ASTRAL4.pdf` - ASTRAL4 tree figure or report.
- `Pygopodidae_AllLoci_Clean_ASTRAL4.tre` - ASTRAL4 tree.
- `Pygopodidae_AllLoci_Clean_hASTRAL.pdf` - hASTRAL tree figure or report.
- `Pygopodidae_AllLoci_Clean_hASTRAL.tre` - hASTRAL tree.
- `Pygopodidae_Genera_AHE.trees` - AHE genus-level tree set.
- `Pygopodidae_Genera_UCE.trees` - UCE genus-level tree set.
- `Pygopodidae_Genera_hASTRAL.tre` - hASTRAL genus-level tree.
- `Pygopodidae_MCMCTree.pdf` - MCMCTree figure or report.
- `Pygopodidae_MCMCTree.tre` - MCMCTree phylogeny.
- `Pygopodidae_MCMCTree_ALL.tre` - Complete MCMCTree phylogeny.
- `Pygopodidae_MCMCTree_RegNo.tre` - MCMCTree phylogeny with registry-number naming.
- `Title_BT.tre` - BayesTraits title tree.
- `Title_Tree.tre` - Title tree.
