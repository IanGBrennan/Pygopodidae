# Diet

This directory holds diet datasets, phylogenetic diet analyses, simulations, scripts, and model results.

## Files

- `00_data_prep.R` - Diet data-preparation script.
- `01_mcmc-diet.R` - Diet MCMC analysis script.
- `02_make-diet-proportions.R` - Diet-proportion processing script.
- `Amphisbaenia_Diets.txt` - Amphisbaenian diet data.
- `DietSimulations.RData` - Saved diet simulation results.
- `Diet_Breadth.pdf` - Diet-breadth results or figure.
- `Diet_README.txt` - Notes for the diet analysis.
- `Plotting_Diet_PCA.R` - Diet PCA plotting script.
- `Squamata_Diets_Families.csv` - Squamate diet data by family.
- `Squamata_Diets_Families.gsheet_alias` - Google Sheets alias for family diet data.
- `Squamata_Diets_Families_OLD.csv` - Older family diet dataset.
- `alldat.csv` - Combined diet data.
- `best_ultrametric_fulltree_ddBD_revision.tre` - Ultrametric phylogenetic tree.
- `diet-proportions-phylo.csv` - Phylogenetically organized diet proportions.
- `diet-proportions-phylo_OLD.csv` - Older phylogenetic diet-proportion dataset.
- `diet_space.R` - Diet-space analysis script.
- `dietname-to-treename.csv` - Diet-name to tree-name mapping.
- `innovate_elaborate.R` - Diet evolution analysis script.
- `mcmc-1000_RESULTS2025.out` - MCMC results for the 1,000-iteration analysis.
- `mcmc-100_RESULTS2025.out` - MCMC results for the 100-iteration analysis.
- `mcmc-20_RESULTS2025.out` - MCMC results for the 20-iteration analysis.
- `mcmc-50_RESULTS2025.out` - MCMC results for the 50-iteration analysis.

## Directories

- `Cavalcanti_Diet_Data/` - Source diet data from Cavalcanti and collaborators.
- `mcmc-out_OLD/` - Older MCMC output files.
