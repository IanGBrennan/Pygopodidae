# Scripts

This directory holds R scripts for data preparation, phylogenetic and comparative analyses, BayesTraits workflows, and visualization.

## Files

- `00_Data_Preparation.R` - General data-preparation workflow.
- `01_BayesTraits_ModelComparison.R` - BayesTraits model-comparison workflow.
- `0X_BayesTraits_Results.R` - BayesTraits results-processing script.
- `0X_Process_BayesTraits_Output_SingleChain.R` - Single-chain BayesTraits output processing.
- `BayesTraits_ModelComparison.R` - BayesTraits model-comparison functions or workflow.
- `Diet_Breadth_PD_Simulations.R` - Diet-breadth phylogenetic simulations.
- `Genera_Reps.R` - Genera-level replicate processing.
- `HBT.R` - Head, body, and tail data analysis.
- `Harmonize_TreeData.R` - Tree and data-name harmonization.
- `VarRates_Functions.R` - Variable-rate analysis functions.
- `Visualize_Locus_Sampling.R` - Locus-sampling visualization.
- `convevol.R` - Convergent-evolution analysis.
- `fabric_Functions.R` - Shared analysis functions.
- `match_HBT_names_to_tree.R` - Matching head, body, and tail names to tree names.
- `plotTree_arc.R` - Arc-style tree plotting.
