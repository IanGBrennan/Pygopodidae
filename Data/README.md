# Data

This directory holds the primary morphological, sampling, trait, and comparative-analysis datasets used in the project.

The raw (unprocessed) morphological data, including references are available on [Google Sheets](https://docs.google.com/spreadsheets/d/1spQTYO9bKFsNZ2rfoNRCdyKFWCamxMxOaAHOCxR1G_I/edit?usp=sharing) and in the `Head_Body_Tail_TreeNames.csv`.

## Files

- `Ancestral_Trait_Estimates.RData` - Saved ancestral-trait estimates.
- `Gecko_Shape.csv` - Gecko shape data.
- `Gecko_Shape_Original.csv` - Original gecko shape data.
- `Head_Body_Tail.gsheet` - Head, body, and tail measurements in spreadsheet format.
- `Head_Body_Tail.xlsx` - Head, body, and tail measurements in Excel format.
- `Head_Body_Tail_June2026.csv` - June 2026 head, body, and tail measurements.
- `Head_Body_Tail_June2026_with_tree_names.csv` - June 2026 measurements matched to tree names.
- `Head_Body_Tail_TreeNames.csv` - Head, body, and tail data with tree names.
- `Pygopodidae_SampleInfo.csv` - Pygopodidae sample metadata.
- `Singularity.csv` - Singularity-related data.
- `SquamBase.csv` - SquamBase data.
- `Squambase_NoHBT.csv` - SquamBase data without head, body, and tail measurements.

## Directories

- `BayesTraits/` - BayesTraits input data and model-comparison results.
